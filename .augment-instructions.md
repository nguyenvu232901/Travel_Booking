# AUGMENT CODING INSTRUCTIONS - TRAVEL BOOKING PROJECT

## Tech Stack
- ReactJS 18.2.0 với Hooks
- React Router DOM v6.6.1  
- Bootstrap 5.2.3 + Reactstrap 9.2.2
- Axios v1.7.7
- Remix Icons
- React Slick + React Responsive Masonry

## Coding Standards
- Sử dụng functional components với React Hooks
- Component-driven architecture
- Code modular, clean, reusable
- Axios cho API interactions (CRUD operations)
- Bootstrap/Reactstrap cho styling
- React Router DOM với useNavigate, useParams
- Remix Icons cho buttons, actions, headers
- React Slick và React Responsive Masonry cho galleries

## Patterns to Follow
- Custom hooks cho API calls (useFetch pattern)
- Context API cho state management (AuthContext pattern)
- RESTful API structure (/api/v1/)
- Error handling trong try-catch blocks
- Loading states trong components
